# VERITAS

Verification Engine for Repository Integrity, Testing & Assessment of Software.

This Space runs the VERITAS API and dashboard. Sign in with the password set in the
Space secret `VERITAS_PASSWORD`. Scan history is stored in the Postgres database given
by the secret `DATABASE_URL`.

Source and documentation: the VERITAS repository on GitHub.
